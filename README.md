# 聚影资源搜索 · DIAN115 插件（发布仓库）

本仓库**只放构建产物和插件市场索引，不含任何源码**。

## 安装

DIAN115 → 插件中心 → 添加仓库，填：

```
https://raw.githubusercontent.com/USER/REPO/main/index.json
```

或在插件中心直接本地导入 `plugins/*.d115p`。

## 更新

插件中心里该插件出现新版本时点「更新」即可；宿主会用 `sha256` 校验下载到的安装包。

## 说明

- 包体已用 Ed25519 签名，签名与完整性清单随包发布，宿主安装时校验。
